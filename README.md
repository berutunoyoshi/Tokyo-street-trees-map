# 東京23区 街路樹マップ

東京都が公開している23区内（都道）の街路樹データ **約14万4千本** を地図上で検索・閲覧できるWebアプリです。
サーバー不要の静的サイトなので、GitHub Pages でそのまま公開できます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 地図表示 | 全樹木を点で表示。樹種（上位10・初期表示）・区分・樹高・幹周で色分け、ヒートマップ（密度）表示 |
| 背景地図 | 地理院タイル（淡色・標準・航空写真）／OpenStreetMap に加え、拡大しても文字や線がぼやけない**ベクトル地図**「くっきり地図（OpenFreeMap）」「地理院ベクトル」を切替。くっきり地図では3D表示中に建物も立体表示（高さはOSMの登録値で、地域により欠ける）。切り替えても選択・絞り込み・計画の表示は保持 |
| 検索・絞り込み | キーワード（樹種・路線名・通称道路名・区。ひらがな可）、樹種の複数選択、行政区、区分、道路種別、路線名、樹高・幹周の範囲、樹木ID（`#123`） |
| 属性の確認 | 点をクリックすると樹種・区分・樹高・枝張・幹周・行政区・種別・路線名・通称道路名・座標を表示 |
| 少ない結果の強調・順送り | 絞り込み結果が500本以下のときは縮小しても見える大きな印で表示。3,000本以下のときは画面下の ◀ ▶ で該当する木を近い順に1本ずつズーム表示 |
| 結果一覧 | 表示範囲内の該当樹木を地図の中心に近い順に表示。結果全体へのズーム、CSVダウンロード |
| 樹種一覧 | 約370樹種を「科別／常緑・落葉／針葉・広葉／高木・中木／五十音／本数順」で整理して表示。23区全体と地図の表示範囲を切替。樹種ごとの本数・平均樹高・多い区や通り・同じ科の樹種を表示し、そのまま地図で絞り込み。一覧はCSVで保存可 |
| 分析：概要 | 本数・樹種数・平均樹高などと、樹種・科・行政区の棒グラフ（クリックで絞り込み） |
| 同じ樹種の中での位置 | 樹木の詳細画面で、同じ樹種の幹周・樹高・枝張の分布（ヒストグラム）と、その木の位置（▼）・上位◯%を表示 |
| 木の選択 | 右下の選択ボタンから「四角形で選択」「指で囲んで選択」（どちらも新規・追加・除外）「上位・下位◯%」「ドリル分析」「絞り込み結果すべて」「表示範囲の木」「台帳から開く」で木をまとめて選択。選択中の木は青い輪で表示し、本数・樹種・平均サイズ・CO2・樹冠・倒木影響範囲を集計 |
| 分析：ドリル分析 | 「区→路線→樹種」「科→属→樹種」「樹高→科→樹種」などの階層で、大分類から小分類へ順に絞り込み。各階層の本数・割合・平均樹高・平均幹周・年間CO2吸収量を表示し、そのまま選択できる |
| 分析：上位・下位 | 幹周・樹高・枝張について、同じ樹種の中で（または対象全体の中で）上位・下位◯%の木を抽出して選択 |
| 倒木影響範囲 | 表示設定から（3D表示中も地面に沿った平面で）、絞り込み条件に合うすべての木について樹高を半径とする円を表示（拡大時）。木の詳細画面では1本ずつ、倒れる方向を指定した帯状の範囲も表示。選択中の木について、範囲内にほかの街路樹がある本数を集計 |
| 計画シミュレーション | 選択した木から計画案を作成し、木ごとの撤去・植え替え・サイズ変更、樹種単位のまとめて植え替え・撤去、新規植栽（1本ずつ／始点と終点を指定した並木）を設定。本数・樹種数・平均樹高・CO2・樹冠面積・倒木影響範囲・樹種構成を現況と比較し、Excel（比較・変更一覧・計画後の樹木一覧・条件）／PDF／ファイルで出力。「計画の範囲だけを表示」では計画後の木だけを3Dで表示し（撤去した木は消える）、年数スライダー（0〜30年）で成長に応じた3D・樹冠・倒木影響範囲・統計の変化を確認、推移をCSV出力。元データは変更しない |
| 元データの修正 | 木の詳細画面から属性の修正・削除、「台帳 → データ修正」から木の追加。この端末に記録して地図・集計に反映し、修正を反映した CSV / trees.json を書き出して元データを差し替えられる |
| 台帳・計画案 | 選択した木に名前とメモを付けて保存。台帳の追加・除外・上書き、ファイルでの書き出し・読み込み（共有用） |
| 出力 | 選択中の木・台帳を Excel（概要・樹種別集計・樹木一覧の3シート）、PDF（印刷画面から保存）、CSV で出力 |
| 分析：CO2・樹冠 | 幹周・樹高からCO2貯留量と年間吸収量を簡易推定、樹冠投影面積の集計、推定方法と外れ値除外の注記 |
| 樹冠表示 | 表示設定から、枝張をもとに樹冠を実寸の円で地図に描画（拡大時） |
| 距離・面積の測定 | 右下の定規ボタンから、地図をタップして距離（区間ごと・合計）と面積（周囲長つき）を測定。面積で囲んだ範囲の木をそのまま選択できる |
| 3D表示 | 表示設定から、樹種ごとの樹形（円錐形・卵形・球形・盃形・枝垂れ形・ヤシ形・株立ち形）で、高さ＝樹高・樹冠の幅＝枝張・幹の太さ＝幹周を反映して立体表示（拡大時、画面中央に近い2,500本）。樹種と樹形の対応は `APP_CONFIG.crownShapes` |
| マイメモ | 樹木ごとに状態・観察日・季節の様子（開花・紅葉など）・メモ・写真（最大4枚）・お気に入りを登録（ブラウザ内に保存） |
| 未登録の木を追加 | 画面中央の十字を木の位置に合わせて、データにない樹木の地点を登録 |
| 書き出し／読み込み | マイメモを JSON / GeoJSON / CSV で書き出し、JSON で読み込み（端末間の移行・バックアップ用） |
| 共有 | URL に地図の位置と選択中の樹木が入るので、そのまま共有できる |
| 現在地 | 現在地の表示・追従、現在地から近い順の一覧、詳細画面に現在地からの距離 |
| スマートフォン対応 | 地図中心の画面＋ボトムシート、ダークモード対応 |

## 点検モード

起動時に「閲覧モード」と「点検モード」を選びます（同じタブ内では再読み込みしてもモードが保たれます。「設定・データ → モード選択に戻る」で切り替え）。

| 機能 | 内容 |
|---|---|
| 点検員の登録 | 開始時に点検員の名前を入力（過去の名前はボタンで選択）。点検記録・写真に記録される |
| シンプルな地図 | 樹種・規格のみ表示。統計・CO2・倒木範囲・3D などは非表示。点の色は 未点検／下書き／判定A〜D／欠株 で区別 |
| 点検入力 | 木をタップすると入力画面。ボタン選択・プルダウン・複数選択・数値・自由記述（マイクボタンで音声入力）・写真（撮影日時・点検員・樹木情報を写真に記録） |
| 必須チェック | 必須項目が未入力だと警告を出して保存できない（未入力の項目を赤枠で表示）。判定C・Dでは緊急度・措置・所見・写真も必須 |
| 判定の目安 | 入力内容から判定A〜Dの目安を表示（最終判断は点検員） |
| マーキング指示 | 判定C・Dを選ぶと、現地マーキング（テープの色・巻き方）を指示するポップアップを表示。実施チェックが必須 |
| 下書き保存 | 判定前でも途中まで保存できる（地図ではオレンジの輪） |
| 次の未点検の木 | 右下の矢印ボタンで、近くの未点検の木へ移動。「絞り込み → 未点検の木だけ表示」も可 |
| 作業記録 | 所定の本数（初期値10本）ごとにポップアップでカメラを起動し、樹木情報付きの作業状況写真を保存。撮り忘れは「作業記録」一覧に赤く表示され、後から撮影できる。Excel・ZIPで出力 |
| 点検一覧 | 日付・点検員・判定で絞り込み、検索、地図で表示、Excel出力 |
| 速報の提出 | 点検日と木を選んで速報（Excel：速報・要対応・作業記録の3シート、写真はZIPで添付可）を作成し、共有メニューからメールアプリへ。宛先は自動でコピー。共有に未対応の端末ではファイル保存＋宛先・件名・本文入りのメール作成画面を開く |
| データの集約 | 各点検員が点検データ（JSON）を書き出し、取りまとめ担当者が取り込んで統合（同じ木は新しい記録を採用、別の点検員と重複した本数を表示） |
| 台帳にない木 | 位置を指定して、台帳にない木も点検できる |

- 点検データ・写真は**各端末のブラウザ内（IndexedDB）**に保存されます。サーバーには送信されません。ブラウザのデータ消去で消えるため、こまめに書き出してください。
- 点検項目・判定区分・マーキングの指示・写真を必須にする判定・作業記録の間隔などは `index.html` 内の `APP_CONFIG.inspect` で変更できます（項目を変えると入力画面とExcelの列も自動で変わります）。
- 音声入力ボタンはブラウザの音声認識（Chrome・Safari など）を使います。使えない場合はキーボードのマイクで入力してください。
- メールアプリの共有では宛先を自動で入れられないため、宛先はクリップボードにコピーされます（宛先欄に貼り付け）。

## ファイル構成

```
├── index.html                  アプリ本体（画面・デザイン・プログラム・設定をこの1ファイルに収録）
├── data/
│   └── trees.json              変換済みの街路樹データ（アプリが読み込む）
├── raw/tokyo_gairoju.csv       元データ（Shift_JIS）
└── scripts/convert.py          CSV → trees.json の変換スクリプト
```

**最低限必要なのは `index.html` と `data/trees.json` の2つ** です（`trees.json` を index.html と同じ階層に置いても動きます）。
設定（初期表示位置・出典表記・クイック検索の樹種・CO2係数・外れ値の基準・倒木影響範囲の倍率）は `index.html` 内の `APP_CONFIG` で変更できます。

樹種の分類（科・常緑/落葉・針葉/広葉、表記ゆれのまとめ）は `index.html` 内の `<script type="text/plain" id="speciesMaster">` にある分類表で管理しています。1行が「データ上の樹種名,標準名,科,属,葉,形,注記」で、科はAPG分類体系です。分類表にない樹種は「未分類」になるので、データ更新時に新しい樹種が出たら追記してください。

## 画面の構成

- **地図が全面**に表示され、上部に検索バーとよく見る樹種のボタン、右下に「表示設定」と「現在地」ボタンがあります。
- 下部メニュー（一覧・樹種・分析・台帳（植栽台帳・計画案）・マイメモ・情報）や木をタップすると、**下からシートが開きます**。シートは上下にドラッグして大きさを変えたり閉じたりできます（PCでは左側のパネルになります）。
- **現在地ボタン**で現在地を表示・追従し、「一覧」で現在地から近い木の順に確認できます（位置情報の利用許可が必要。https で公開されている必要があります）。

## GitHub で公開する手順

1. GitHub で新しいリポジトリ（例：`tokyo-street-trees`、Public）を作り、`index.html` と `data/trees.json` をアップロードします（`raw/`・`scripts/` などは任意）。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **「Deploy from a branch」** を選び、Branch を `main`・フォルダを `/ (root)` にして保存します。
3. 数分で `https://<ユーザー名>.github.io/tokyo-street-trees/` に公開されます。

> 以前の版で Source を「GitHub Actions」にしていた場合は、上記の「Deploy from a branch」に切り替え、リポジトリ内の `.github` フォルダと `data/reports.json` は削除してください。

## データの更新

新しい CSV が公開されたら `raw/` に置き換えて変換し、push します。

```bash
python3 scripts/convert.py raw/tokyo_gairoju.csv data/trees.json
```

- 文字コード（Shift_JIS / UTF-8）は自動判別します。外部ライブラリは不要です。
- **樹木ID は CSV の行番号（0始まり）** です。データを差し替えると ID と樹木の対応が変わり、既存のマイメモの紐付けがずれる可能性があります（マイメモには座標も保存されています）。

## ローカルで確認する

`fetch` でデータを読み込むため、`index.html` を直接開くのではなく簡易 Web サーバーを使います。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 外れ値の扱いとCO2推定

- **外れ値の除外**：樹高・枝張・幹周のそれぞれについて、同じ樹種（標準名）・区分（高木/中木）の分布（対数値）で「第3四分位＋3×四分位範囲」かつ「中央値の3倍」を超える値、および上限（樹高35m・枝張25m・幹周600cm）を超える値・0以下の値を外れ値とし、平均・CO2・樹冠の集計から除外します。基準は `APP_CONFIG.outlier` で変更できます。除外した木の一覧は「分析 → CO2・樹冠」から確認できます。
- **CO2推定**：胸高直径（幹周÷π）と樹高から幹材積を求め、容積密度・拡大係数・地下部比・炭素含有率を掛けてCO2量に換算する簡易推定です。年間吸収量は胸高直径が年0.5cm太ると仮定した増加分です。係数は `APP_CONFIG.carbon` で変更できます。
- **樹冠**：枝張を直径とする円で面積を計算します。枝張の欠損・外れ値は、同じ樹種・区分の中央値で補完します（地図上では薄い円で表示）。
- **同じ樹種の中での比較**：樹種×区分の本数が20本以上ならその中で、少なければ樹種全体で比較します（`APP_CONFIG.compare`）。外れ値は比較から除外します。
- **倒木影響範囲**：半径＝樹高×`APP_CONFIG.fall.factor`（既定1.0）の円。地形・傾き・根の状態・風は考慮しない幾何学的な目安です。
- **計画シミュレーション**：新規植栽・植え替えの標準サイズ（植栽直後）は高木 樹高3.5m・幹周20cm・枝張1.5m、中木 樹高1.5m・枝張0.8m で、`APP_CONFIG.plan` で変更できます。比較は完成直後の状態で、植栽後の成長は考慮しません。
- **成長シミュレーション**：毎年の成長量＝基準成長量×（1−現在の大きさ÷上限）の簡易モデル。基準成長量（高木：樹高0.45m・幹周2.5cm・枝張0.3m／年、中木：0.12m・0.8cm・0.1m／年）と上限（同じ樹種・区分の上位5%の大きさ）は `APP_CONFIG.growth` で変更できます。剪定・枯損は考慮しません。
- **元データの修正**：修正はこの端末の IndexedDB に記録され、読み込み時に元データへ重ねて反映します。「trees.json（修正反映済み）」を書き出して GitHub の `data/trees.json` を差し替えると全員に反映されます（樹木IDが振り直される点に注意）。
- **保存先**：マイメモ・植栽台帳・計画案は、その端末のブラウザ内（IndexedDB）に保存されます。ほかの人と共有するときは台帳をファイルに書き出して渡し、相手が読み込みます。
- **属**：樹種の分類表に「属」の列があり、樹種の情報画面に表示します。サクラ属はウメ・モモ等を含む広義です。
